Search & Rescue System

A rapid-response payload system that safely delivers a locator beacon and a water bottle from above 150 ft AGL.

  • Soft-mounted magnetic connectors trigger the descent logic once the payload drops
  • Led parachute recovery from start to finish: chose the 24" Top Flight Recovery X-chutes, designed the printed TPU harness and foam ejection block that pack them, and drop-tested the full system
  • Water bottle and beacon payloads drop from modified E-flite EFLA405 servoless releases
  • ESP8266-based microcontrollers run the parachute deployment logic
  • Reduced fasteners by using multi-material 3D printing
  • Logged drop-test data and processed it in MATLAB to tune release timing and placement
