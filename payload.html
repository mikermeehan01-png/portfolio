SUAS Parachute System

A quick-release payload system that carries a locator beacon and a water bottle, each recovered under its own parachute.

  • Designed a quick-release mount with a pogo-pin connector, so payloads swap on the aircraft without rewiring
  • Ran parachute recovery end to end: selected 24" Top Flight Recovery X-type chutes, packed them in a printed TPU harness with a foam ejection block, and drop-tested
  • Water bottle and beacon payloads drop on E-flite EFLA405 servoless releases
  • WeMos D1 Mini microcontrollers run the release logic and the locator beacon
  • Logged drop-test data and processed it in MATLAB to tune release timing and placement

CUASC System

1st place, package drop

Purpose-built release modules for each CUASC package type, on a common quick-release adapter.

  • Built a release module for each package type: a flexible TPU mesh for beanbags and a servo-driven cage for cubes
  • Beanbag modules drop on E-flite servoless releases; the cube cage releases on an MG995 servo
  • Both modules mount on a shared quick-release adapter
  • Took 1st place in the CUASC package drop challenge
