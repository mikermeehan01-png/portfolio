# Mike Meehan: Engineering Portfolio

Static site for GitHub Pages. No build step: edit the HTML and push.

- Pages: `index.html`, `payload.html`, `aircraft.html`, `vtol.html`, `psa.html`, `other-projects.html`
- Styles: `css/site.css`. Scroll animation and video handling: `js/site.js`
- Images in `img/`, videos in `video/` (keep each clip a few MB, H.264 MP4, muted)

## Common edits
- Bullets and text: edit the `<li>` and `<p>` tags directly in the page.
- Resume: add `resume.pdf` to this folder. The Resume buttons appear automatically.
- Gray Goose specs: fill in the table in `aircraft.html` and delete its `hidden` attribute.
